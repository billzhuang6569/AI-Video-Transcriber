API Access

Use it from any agent or script

Submit a YouTube, Bilibili, Douyin page/share URL or a direct media URL, then poll the normalized result.

POST /api/transcribe-url

Create a routed async task from a platform page or direct media URL.

GET /api/transcribe-url/{task_id}

Poll until status becomes completed, cancelled, or error.

POST /api/transcribe-url/{task_id}/cancel

Stop a running task while keeping its final status available.

BASE_URL="http://206.223.84.125:8020"

curl -X POST "$BASE_URL/api/transcribe-url" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/video.mp4",
    "prefer_subtitles": true,
    "transcription_provider": "elevenlabs",
    "transcription_model": "scribe_v2"
  }'

curl "$BASE_URL/api/transcribe-url/TASK_ID"

curl -X POST "$BASE_URL/api/transcribe-url/TASK_ID/cancel"

Async by default Large videos return quickly with task_id instead of blocking the request.
Fixed response Every result uses status, data, error, task_id, progress, and message.
Server keys Transcription provider and TikHub keys are configured on the server; clients do not need to send keys.
